## Medical Crowdfunding Platform

A full-stack web application built with Django and MySQL that connects patients in need of medical funding with donors and hospitals.

### Features
- 4 role-based portals — Admin, Hospital, Donor, and Patient
- Hospitals register and get approved by Admin
- Patients are registered by hospitals and can request funds
- Donors can browse patients and contribute via online payment
- Admin can monitor, approve, and stop/resume funding
- Expense tracking, feedback system, and fund completion reports
- Forgot password functionality

### Tech Stack
- Backend: Python, Django
- Database: MySQL
- Frontend: HTML, CSS, JavaScript

### How to Run
pip install django
python manage.py runserver

Then open http://127.0.0.1:8000
